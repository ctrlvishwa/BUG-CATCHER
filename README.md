# 🐛 AI Bug Catcher (Terminal Edition) ⚡

An AI-powered, full-stack code analysis tool designed to instantly hunt down vulnerabilities, logic flaws, and style issues in any programming language.

## 🔗 Live Demo
Check out the live application: [https://bug-catcher-ai.onrender.com/](https://bug-catcher-ai.onrender.com/)

## 🛠️ Tech Stack
* **Frontend:** HTML5, Modern CSS (Responsive Design), JavaScript (ES6+)
* **Backend:** Node.js, Express.js
* **AI Engine:** Groq API (Llama 3 8B model for lightning-fast inference)
* **Hosting & Automation:** Render (Deployment), UptimeRobot (Uptime Monitoring)

## 💡 Features
* **Zero-Latency Feel:** Uses backend routing to keep the API keys secure and an uptime pinger to prevent cold starts.
* **Instant Analysis:** Structured output highlighting bugs, security risks, and style refactoring.
* **Responsive Dark Mode:** Built with a clean developer-first aesthetic.
