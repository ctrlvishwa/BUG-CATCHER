# 🐛 AI Bug Catcher (Terminal Edition) ⚡

An AI-powered, full-stack code analysis tool designed to instantly hunt down vulnerabilities, logic flaws, and style issues in any programming language. 

Built with a custom MS-DOS/Matrix inspired retro-terminal UI, this application leverages the blazing-fast inference speeds of the **Groq API** and **Llama 3.1** to act as an automated Senior Developer code-reviewer.

### 🚀 Technical Highlights
* **Generative AI Integration:** Communicates with LLMs via the Groq SDK for near-instant code analysis.
* **Full-Stack Architecture:** Custom `Node.js` / `Express` backend server securely handles API keys and routes traffic from the Vanilla JS frontend.
* **Security First:** Features strict API payload validation and XSS (Cross-Site Scripting) protection on data rendering.
* **Custom UI/UX:** fully tech friendly and vibes that grab you up  terminal aesthetic with CSS animations.
